NONDATUM_LEDGER_ICONS

Категории книги недатумных аллокаций. Номера, а не строки: книга - плоский числовой список, и индекс по константе дешевле поиска по ключу в горячем проке.

Лежат отдельно от самой книги (code/__HELPERS/nondatum_ledger.dm), потому что их зовут файлы, которые включаются раньше неё: icons.dm стоит в tgstation.dme выше __HELPERS, а дефайн, объявленный позже первого использования, для DM просто не существует. Иконок собрано (getFlatIcon, icon2html мимо кэша, icon2base64 и родня).
