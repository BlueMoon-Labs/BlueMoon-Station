MOB_INDIVIDUAL_LOG_MAXСколько записей ОДНОГО типа держится в индивидуальном логе моба и его player_details.

Define Details

#define
MOB_INDIVIDUAL_LOG_MAX

Сколько записей ОДНОГО типа держится в индивидуальном логе моба и его player_details.

Каждая запись - ассоциативный список из тринадцати полей, и держится она дважды: у моба и у player_details, который живёт весь раунд по ckey. Без предела это накопитель, растущий пропорционально активности станции; полная история при этом никуда не девается - она в файлах раунда. Двести на тип - это несколько часов болтовни или пара крупных драк, то есть заведомо больше, чем админ отматывает в лог-вьювере.
