code/__HELPERS/files.dm

/proc/md5filepathReturns the md5 of a file at a given path. Нативный хеш rust-g: BYOND'овский md5(file()) на путях с диска блокировал тик на ~20мс за файл (генерация ассетов при коннектах). Читает файл напрямую с диска, минуя маршаллинг в BYOND.
/proc/md5asfileSave file as an external file then md5 it. Used because md5ing files stored in the rsc sometimes gives incorrect md5 results.
/proc/is_safe_path_for_admin_shellBasic checks so shelleo / shell snippets are not abused via crafted paths (admin-only endpoints, still).
/proc/shell_single_quote_pathSingle-quote a path for POSIX sh -c (e.g. wrapping stat / head arguments).
