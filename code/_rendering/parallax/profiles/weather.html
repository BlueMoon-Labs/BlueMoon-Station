Space Station 13 - Modules - Types

code/_rendering/parallax/profiles/weather.dm

/datum/parallax_profile/weatherПрофили космической погоды и планетарных явлений.
/datum/parallax_profile/weather/bluespace_stormБлюспейс-шторм. Ярусы глубины вместо одной плоской картинки Eris. Фоновый ярус не берётся: замер показал чистую черноту (см. layers/weather.dm).
/datum/parallax_profile/weather/graveyardКладбище кораблей: крупные обломки станций на среднем ярусе.
/datum/parallax_profile/weather/micro_debrisПоле мелких обломков. Дальний ярус - единственный бесшовный стейт Eris.
/datum/parallax_profile/weather/ion_blizzardИонная буря. Ближнего яруса у художника Eris нет, поэтому их только два.
/datum/parallax_profile/weather/bluespace_interphaseБлюспейс-интерфаза: ровный фон без ярусов, для аномальных зон.
/datum/parallax_profile/weather/photon_vortexФотонный вихрь: чёрная дыра во весь фон, поверх неё редкие звёзды.
/datum/parallax_profile/weather/goon/snowПланетарная погода идёт парами: спокойный фон мира и его же буря.
/datum/parallax_profile/weather/goon/snow/stormЕго же буря. Ставится самой погодой, автоподбором не выпадает.
/datum/parallax_profile/weather/goon/embersПепел и угли. Исходник почти чёрный (яркость 34 из 255), поэтому коэффициент маски плотности здесь втрое больше снежного. Угли поднимаются, а не падают - отсюда угол 180.
/datum/parallax_profile/weather/goon/embers/stormПепельная буря. Ставится самой погодой.
/datum/parallax_profile/weather/goon/dustПыльная буря. Без гейта по трейтам - запасной вариант для любой планеты. Пыль несёт вбок, а не сверху вниз.
/datum/parallax_profile/weather/goon/dust/stormПыльная буря. Резерв для планетарных погод, которым нечего показать своего.
/datum/parallax_profile/weather/goon/blowoutВыброс: событийный профиль планетарных уровней, ставится только вручную.
/datum/parallax_profile/weather/goon/voidПустота: чернота и два яруса разреженных облаков.
/datum/parallax_profile/weather/goon/asteroid_beltАстероидный пояс из трёх плотностей. Станции не достаётся: её фон закреплён за space_classic, см. profiles/space.dm.
/datum/parallax_profile/weather/layeniaLayenia: четыре слоя Shiptest работают только вместе. Горизонт задаёт линию, три яруса облаков расходятся по скорости; по отдельности каждый бессмыслен. Только планетарные уровни: это яркое небо (средняя яркость кадра 187 из 255), и над руиной в открытом космосе оно читалось бы как засвет, а не как небо.
