Space Station 13 - Modules - Types

code/datums/datum_census.dm

/var/datum_census_createdПерепись НЕ-атомных датумов: сколько их создано за раунд и сколько пережило qdel.
/var/datum_census_destroyedТип -> сколько раз отработал /datum/Destroy(). Атомы сюда попадают тоже, но в отчёт не идут: отчёт перебирает ключи created, а туда атом не доходит (см. комментарий про /atom/New()).
/var/datum_census_snapshot_createdСнимок created на прошлой переписи. Отчёт отдаёт РАЗНИЦУ: за раунд создаётся полмиллиона /mutable_appearance, и в абсолютном топе кроме них не видно ничего и никогда.
/var/datum_census_snapshot_residueСнимок остатка "создано минус qdel" на прошлой переписи, по той же причине.
/proc/datum_census_linesСтроки переписи датумов для лога мира плюс обновление снимка.
/proc/datum_census_residueОстаток по типам: создано минус ушедшее через qdel.
/proc/datum_census_report_linesСборка строк отчёта из счётчиков и снимка прошлой переписи.
/proc/datum_census_growthРазница двух срезов переписи датумов: тип -> насколько его стало больше.
