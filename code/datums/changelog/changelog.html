code/datums/changelog/changelog.dm

/proc/changelog_archive_monthsМесяцы архива ченджлога ("YYYY-MM"), свежие первыми.
/proc/changelog_latest_entry_dateСамая свежая дата записи ("YYYY-MM-DD") в последнем месяце архива, или "" если архив пуст.
/proc/changelog_testmerge_entriesТест-мерджи для окна: номер, название, автор, ссылка и записи :cl: из тела PR. PR с [s] в названии или авторе - секретные, их видят только админы (как в Show Server Revision).
/proc/changelog_parse_clЗаписи блока :cl: ... /:cl: из описания PR, как их читает tools/changelog/generate_cl.py: "тег: текст", без строк-заглушек из шаблона.
/proc/sanitize_changelog_dateДата в формате "YYYY-MM-DD" или "" для всего остального.
