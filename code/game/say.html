Space Station 13 - Modules - Types

code/game/say.dm

/proc/get_radio_job_styleОформление тега должности: классы отдела, фракции и главы для чата, id прежней раскраски и значок. Цвета задаёт чат. Отдел, глава и значок - по показанному названию shown_job (custom_job карты), свободный текст - по профессии карты base_job. Без карты (КПК) префикс наклейки снимается только перед точным названием профессии: "Syndicate Admiral" не капитан.
/proc/radio_job_stylelegacy - id прежней раскраски (radiojob-legacy-), icon_states - стейт icons/ui_icons/tgui/jobs.dmi или список, берётся первый из листа.
/proc/is_radio_job_headМетка главы в теге должности рации с аргументами get_radio_job_style().
/proc/get_radio_role_iconСтейт jobs.dmi роли вне SSjob по её названию. Только явный список: неточное название профессии ("Captain!", "A.I.") чужого значка не получает.
/proc/get_radio_shown_jobПрофессия названия: профессия карты, если это её название или альт-название, иначе однозначная чужая, неоднозначное - свободный текст. GetJobName() тут не годится: в real_job_name общие альт-названия перезаписывают друг друга.
/proc/get_radio_job_departmentОтдел профессии, а без своих битов отдела - отдел её начальника.
/proc/get_radio_job_legacy_classРаскраска до разделения по отделам: настройка чата "По профессии (как раньше)".
/proc/get_radio_head_jobsГлавы - профессии, которые другие профессии называют своим department_head.
