code/game/director/director_signals.dm

/datum/director_signalsМгновенный снимок состояния раунда для решений директора.
/proc/is_effective_crew_mobЯвляется ли моб экипажем с точки зрения директора (без проверки клиента/AFK - их проверяет счётчик; это позволяет юнит-тестировать классификацию).
/proc/director_dept_of_jobОтдел станционной должности или null, если должность не станционная (гост-роль). allow_other: считать станционными и должности вне шести отделов (ассистент и пр.).
/proc/director_has_living_roleЕсть ли живой персонаж с одной из перечисленных должностей. Обход SSticker.minds (записей - по числу заходивших игроков), а не GLOB.alive_mob_list (тысячи, почти всё - фауна без mind): гейты "есть ли живой врач" зовутся битом директора по несколько раз в минуту.
