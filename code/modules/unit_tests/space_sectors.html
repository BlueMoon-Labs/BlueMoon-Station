/datum/space_sector/unit_testСекторы космоса: раскладка по сетке, вертикальные стопки, гейты и проходимость космоса по вертикали. Тестовый набор секторов: компилируется только с UNIT_TESTS, на боевые карты попасть не может.
/proc/unit_test_build_space_gridСобирает тестовый набор на выдуманных z-номерах и возвращает готовую сетку.
/datum/unit_test/space_sector_declarationsРеестр секторов собирается из объявлений, валидируется и выдаёт свежие трейты каждому уровню.
/datum/unit_test/space_grid_layoutСетка космоса связывает соседей по горизонтали и замечает одностороннюю явную связь.
/datum/unit_test/space_grid_cell_conflictЗанятая клетка сетки не отдаётся второму уровню, плавающий встаёт вплотную к занятой.
/datum/unit_test/map_template_z_trait_setsНаборы трейтов шаблона раздаются каждому этажу и не делят один список.
/datum/unit_test/map_template_stack_linkingСвязка этажей шаблона взаимна, объявленная маппером вертикаль не перетирается.
/datum/unit_test/space_turf_vertical_passageКосмос пропускает по вертикали в обе стороны, кроме прикрученного; пол только впускает сверху.
/datum/unit_test/sector_gate_pairingПарные гейты находят друг друга, переносят груз по направлению и помечают прибывшего.
/datum/unit_test/space_grid_upper_floor_edgesВерхний этаж стопки без соседей на своей высоте выходит к соседним секторам ниже, а не замыкается на себя.
