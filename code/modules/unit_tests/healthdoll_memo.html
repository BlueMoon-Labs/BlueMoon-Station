Tests for the healthdoll memoization in /mob/living/carbon/human/update_health_hud().

The doll used to be torn down (cut_overlays) and rebuilt from scratch — up to ten mutable_appearance() + add_overlay() calls plus two full-body limb walks — on EVERY health change, which in round 9800 made /proc/mutable_appearance the third most expensive proc in the whole server profile.

The rebuild is now gated on a cache key. These tests pin the contract that makes that gate safe:

key unchanged <=> rendered overlay set unchanged

If the key ever stops tracking something the renderer reads, the doll silently stops updating in game — so the equivalence is asserted in both directions. Damages a bodypart without letting wounds/dismemberment interfere.
