Define Details

#define
MC_STATE_COST_SAMPLES

Сколько раз подряд собирается текст сводки в замере цены.

Тысяча, потому что REALTIMEOFDAY меряет децисекундами: сотня сборок по полсотни микросекунд уложится в один отсчёт таймера, и замер покажет ноль при любой регрессии.

#define
MC_STATE_TEST_FILE

Куда пишут тесты, чтобы не топтать боевой data/mc_state.txt: его прямо сейчас переписывает петля МК.

#define
MC_STATE_WRITE_SAMPLES

Сколько записей на диск делает замер цены записи.

На порядок меньше, чем сборок текста: запись дороже и на медленной файловой системе тысяча записей встала бы в десяток секунд теста. Двухсот хватает, чтобы сгладить замер.
