code/modules/asset_cache/spritesheet/batched/universal_icon.dm

/datum/universal_iconЗамена /icon для спрайтшитов: описывает иконку и цепочку операций над ней, но ничего не рисует. Рисует потом rust-g (IconForge) - разом по всему листу и в несколько потоков, вместо десятков тысяч DM-овых icon()/Blend().
/datum/icon_transformerЦепочка операций над иконкой. Формат элементов - ровно тот, что ждёт IconForge, см. RUSTG_ICONFORGE_* в code/__DEFINES/rust_g.dm.
/proc/icon_transformer_from_listОбратная операция к /datum/icon_transformer/to_list()
/proc/color_transformГотовый трансформер с домешанным цветом.
/proc/dmi_frame_dimensionsРазмер кадра DMI по пути к файлу - без загрузки иконки в DM.
/proc/get_display_icon_forИконка типа для превью в UI: как атом выглядит "из коробки".
