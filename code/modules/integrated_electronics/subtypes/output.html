Define Details

#define
SCREEN_REBROADCAST_WINDOW

Через сколько экран имеет право повторить то же самое значение ещё раз.

Дедуп по значению без этого окна глушил повторяющуюся тревогу навсегда: датчик движения, написавший "INTRUDER" на первом нарушителе, на всех следующих молчал до конца раунда, потому что строка не менялась. Окно возвращает повтор, не возвращая спама: самопульс дёргает do_work() по нескольку раз в секунду, тут же он ограничен одной строкой в 10 с.
