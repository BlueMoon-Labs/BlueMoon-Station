Space Station 13 - Modules - Types

code/modules/integrated_electronics/core/assembly_tgui.dm

/proc/ie_ic_get_debugger_from_handsPrefer active hand: tool there → use as ref; else debugger in either hand.
/proc/ie_ic_tgui_apply_marked_atom_or_debuggerTGUI upload: debugger (copy from pin / paste memory), held item ref, or varedit mark. Works for all data-channel pin types.
/proc/ie_ic_write_debugger_memoryПишет память отладчика (data_to_write: скопированное значение / ref / null) в пин данных с приведением типа по ftype. Возвращает TRUE в случае записи, иначе FALSE (сообщение пользователю при этом уже выводится).
/proc/ie_ic_paste_debugger_valueВставляет память отладчика в открытый пин нативного редактора (данные: скопированное значение / ref / null — в зависимости от того, что сейчас в памяти отладчика).
/proc/ie_ic_tgui_port_colorЦвет точки порта в TGUI (имена из CSS_COLORS); по возможности как у wiremod.
/proc/ie_ic_tgui_pack_pin_valueJSON-friendly value for TGUI (nested lists, refs as names). Does not mutate pin data.
/proc/ie_ic_value_widget_kindТип значения в терминах TGUI-виджетов (для нативного редактора списка/текста).
/proc/ie_ic_pack_list_entryСериализация значения ЯЧЕЙКИ списка для нативного редактора. Возвращает ассоциативный список {kind, display, value}; value это JSON-безопасное представление для обратной записи.
/proc/ie_ic_ref_display_nameЧитаемое имя ссылки (ref) для ячейки списка; не падает на не-atom и на удалённых целях.
/proc/ie_ic_editor_payloadДерево «открытого в нативном редакторе» пина для ui_data. Per-user-ключ пином не является, т.к. окно TGUI у пользователя одно; редактор показывает значение последнего открытого пина.
/proc/ie_ic_decode_list_textЧитает строку из TGUI и превращает в подходящий DM-тип для записи в список (по kind).
/proc/ie_ic_output_connected_input_refsВходы, подключённые к этому выходу (порядок = порядок линий на схеме).
/proc/ie_ic_serialize_live_pulsesСериализует все «живые» импульсы (out/in ref) в порядке активации для TGUI.
/proc/ie_ic_get_editor_pinВозвращает {io, is_output} открытого в редакторе пина для сборки или одиночного чипа, либо null, если пин уже исчез (чип снят). shared-источник для ui_data и ui_act.
/proc/ie_ic_set_editor_pinУстанавливает открытый в нативном редакторе пин; см. ie_ic_get_editor_pin.
/proc/ie_ic_obtain_ref_for_uploadДостаёт weakref для вставки в pin/список: память-ref отладчика → предмет в активной руке → marked-датум админа. Возвращает weakref или null (с сообщением уже не пишет).
/proc/ie_ic_copy_pin_to_debuggerКопирует текущее значение пина в память отладчика (пин → debugger).
/proc/ie_ic_list_mutateВписывает значение из нативного редактора в список (пин-список или «any» со значением-списком).
/proc/ie_ic_handle_editor_actionОбработка действий нативного редактора пинов. Возвращает TRUE, если action был наш.
/proc/ie_ic_remove_connection_atУдаляет одну конкретную связь пина по 1-based индексу в порядке списка связей (тот же порядок, что TGUI показывает в попапе «Порядок связей»). Возвращает TRUE, если связь была разорвана.
