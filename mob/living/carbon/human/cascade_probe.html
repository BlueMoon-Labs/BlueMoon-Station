cascade_probe
/mob/living/carbon/human/cascade_probe

Tests for the cost of the carbon health-update cascade.

updatehealth() -> update_stat() -> everything is the hottest mob path on the server (12.9% of all Master Controller time in round 9800, at ~112 calls per second). These tests pin down which parts of that cascade are allowed to run on every single health change and which are not. Human that counts how often the expensive tail procs are re-entered, so the tests can assert on call counts instead of on side effects that need a client to observe.
