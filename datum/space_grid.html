space_grid
/datum/space_grid

Сетка космоса: кто в какой клетке стоит и кто кому сосед. Ни турфов, ни загрузки - только топология.

Vars

cells"x,y,этаж" -> /datum/space_level
frontierСвободные клетки нулевого этажа по границе занятых.
level_sectorsdatum/space_level -> /datum/space_sector, только у объявленных уровней.
placementsdatum/space_level -> list(x, y, этаж)
sector_levelsid сектора -> /datum/space_level

Procs

apply_explicit_linksЯвные связи по id поверх координат. Обратную сторону сосед объявляет сам.
link_horizontalСоседство по координатам: каждая пара получает взаимные ссылки, пустые стороны остаются незаполненными.
link_upper_floorsЭтаж выше нулевого без соседа на своей высоте выходит к соседней клетке на её ближайший этаж ниже. Обратно ведёт связь того этажа.
placeСажает уровень в клетку. FALSE, если клетка занята: занявший остаётся, претензия уходит в problems.
place_floatingУровень без объявленной клетки: случайное блуждание по свободной границе занятых.
to_asciiТекстовая карта сетки для дампа: таблица на этаж, в клетке номер z.
validateПолный отчёт: problems плюс проверки, осмысленные только на собранной сетке.
vertical_pairsПары уровней, стоящих друг над другом: list(нижний, верхний).
