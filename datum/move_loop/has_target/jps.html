target_drifted_from_pathTRUE when the cached route no longer ends anywhere near the target. The path is planned once for wherever the target stood, and the loop only rebuilds it when the cache runs out - so the longer the route, the longer the mover chases a stale destination (a door the target left seconds ago). repath_cooldown keeps the rate bounded, so a moving target costs at most one extra search per repath_delay.

TRUE when the cached route no longer ends anywhere near the target.
