assign_oranges_ears
(/list/atoms_that_need_ears)

Расставить по одному /mob/oranges_ear на каждый турф, содержащий атомы из atoms_that_need_ears, и раздать ушам ссылки на их атомы. Если на турфе уже стоит ухо этого запроса - атом просто дописывается к нему.

has_living_client_in_range
(/atom/center, range)

TRUE as soon as a living client mob is found inside the exact range. Unlike orthogonal_range_search(), this does not build and concatenate a temporary result list for every clientless mob processed by SSmobs.

proc
orthogonal_range_search
(/atom/center, type, range)

Ортогональный поиск: собрать содержимое канала type из всех ячеек, пересекающих квадрат со стороной 2*range вокруг center.

ВАЖНО: возвращает содержимое ЯЧЕЕК, то есть больше, чем радиус range - дистанцию до конкретной цели фильтруйте сами (get_dist).
