hk_terminal
/datum/hk_terminal

Встроенный контрактный терминал HK-47: окно HKContractTerminal.

Vars

sent_photos_keyКакие снимки ушли в static data последними; при смене досье static data отправляется заново.

Procs

collect_photosНомер досье -> снимок цели; getFlatIcon дорогой, поэтому снимок один на контракт и только в static data. Новые снимки делает take_next_photo() по одному за тик: пачка досье разом стоила до 0.45 с стоп-кадра (раунд 10618).
photos_keyНомера досье, у которых есть снимок; засекреченная цель охоты появляется здесь только после опознания. Отметка готового снимка в ключе: снимок, ушедший в ещё не готовое окно, ui_data отправит повторно.
shown_contractsДосье в окне: предложения и активный контракт.
suspectsИгроки в паре клеток от HK, которых он видит, для опознания: имя видно и так, цель среди них не отмечена.
take_next_photoСледующий снимок взводится здесь же: кулдаун полного обновления окна не должен растягивать очередь досье.
