bodypart_overlay
/datum/bodypart_overlay

Abstract parent. Each instance represents one visual layer drawn on a bodypart. An /obj/item/bodypart holds a list of these in its bodypart_overlays var.

Vars

blocks_emissiveWhether this overlay casts an emissive shadow (blocker) on the emissive plane.
draw_on_husksWhether the overlay should be drawn on husked owners (see HUSK_OVERLAY_*)
layersAssoc list [layer postfix string] -> [positive layer number]. The postfix is passed to the child get_image() as layer_index, and the layer is negated before being passed as layer_real (bodypart overlays use negative draw layers).
offset_locationHow the overlay offset is modified. Reserved for future use (kept for port parity).

Procs

color_imageOverridden by subtypes to tint the overlay (e.g. skin / species colors).
get_all_overlaysReturns every mutable appearance this overlay contributes to the limb at every layer.
get_imageOverridden by subtypes to return the actual main image for a layer.
get_overlayBuilds the list of images for one layer of this overlay. layer_index = the string postfix (e.g. "ADJ"), layer_real = the negated draw layer.
huskify_imageApplies the husk color tone to the overlay for husked owners.
icon_render_keyReturns extra data appended to the mob's icon render key so the limb icon cache is correctly invalidated when this overlay's appearance changes.
set_appearanceRebuilds the overlay's appearance from its source (organ, feature, etc).
