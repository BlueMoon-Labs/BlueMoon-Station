Space Station 13 - Modules - Types — Var Details - Proc Details

admin_log_viewer
/datum/admin_log_viewer

TGUI-браузер серверных логов: навигация по data/logs, постраничный просмотр, поиск, live-tail текущего раунда, скачивание файлов и архива раунда.

Vars

cached_contentКэш целиком прочитанного файла (только для файлов <= ADMIN_LOG_WHOLE_READ_MAX).
current_fileОткрытый файл (имя в текущем каталоге) и его состояние просмотра.
last_page_actТроттлинг страничных чтений (спам кнопками пейджера не должен дёргать диск чаще ~2 раз/сек).
listingКэш листинга текущего каталога.
ownerКлиент-владелец панели.
page_bytesВыбранный размер страницы в байтах; 0 - режим "весь файл" (кап ADMIN_LOG_WHOLE_PAGE_MAX).
path_segmentsТекущий каталог как список проверенных сегментов относительно ADMIN_LOG_ROOT.
search_resultsРезультаты серверного поиска по файлу.
tail_activeРежим live-tail: активен ли и id зацикленного таймера.

Procs

cleanup_archive_dirОдноразовая чистка остатков архивов с прошлого запуска сервера. Зовётся до первой сборки этого запуска, так что удалять можно всё подряд.
current_dir_pathАбсолютный путь текущего каталога, всегда с завершающим "/".
current_file_pathАбсолютный путь открытого файла или null.
download_archiveСкачать текущий каталог одним архивом (рекурсивно): раунд, день или месяц целиком.
download_selectedСкачать несколько выбранных файлов текущего каталога: один - напрямую через ftp, несколько - одноразовым архивом (уникальное имя, без кэша и лока сборки).
effective_page_bytesФактический размер страницы с учётом режима "весь файл".
fetch_listing_metaРазмеры и mtime всех файлов каталога одним shell-вызовом (только Unix). null - метаданных нет, вызывающий падает на поштучный admin_log_file_size без mtime.
jump_toПерейти к произвольному списку сегментов (уже валидированных).
load_pageЗагрузить страницу с байтового смещения. already_aligned - смещение уже указывает на начало строки (начало файла, page_end предыдущей страницы, результат поиска).
tail_availableTail доступен только для файлов внутри каталога текущего раунда.
try_open_fileОткрыть файл по имени из текущего каталога. Имя повторно сверяется с диском.
