antag_training_sector
/datum/antag_training_sector

Vars

booking_seen_atКогда в секторе последний раз видели кого-то из группы брони.
landmark_offsetsМетки мест для ролей: id метки -> смещение клетки от угла слота.
priority_queueГруппы из очереди, которым сектор ещё не предлагали; занять его сейчас может только priority_squad.
scenario_side_orderВ каком порядке своя сборка раскладывает стороны по меткам сектора.
side_offsetsМетки сторон сценария: сторона -> список смещений.

Procs

after_loadДоводка загруженного шаблона: свои провода вместо раскладки раунда, связь солнечных панелей, выключенные GPS. Результат place() отдаёт в load(): переопределение без . = ..() или return TRUE срывает каждую загрузку.
collect_landmarksЗапоминает, где в шаблоне стоят метки мест для ролей и сторон сценария, и убирает сами метки.
dissolveРастворение видят и слышат только те, кто стоит в секторе; пустой сектор выгружается без задержки.
edge_tilesКлетки края сектора: сторона -> список клеток; угловая клетка входит в две стороны.
entry_refusalПочему сеанс не может войти в сектор, или null.
landmark_turfКлетка метки места для роли или null, если метки нет или сектор не готов.
offer_priorityПредлагает сектор следующей группе очереди на ANTAG_TRAINING_BOOKING_PRIORITY. TRUE - окно открыто.
priority_holderГруппа, за которой сейчас придержан сектор; просроченное или ненужное окно уходит следующей.
scenario_runningПартия группы брони идёт в этом секторе: срок и простой брони её не прерывают.
set_frameГолографическое поле по краю: по оверлею на сторону клетки края, без своих атомов.
sweepГолограмма проходит по сектору волной: снизу вверх при загрузке, сверху вниз при растворении.
