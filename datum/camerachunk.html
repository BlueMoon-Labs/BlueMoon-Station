camerachunk
/datum/camerachunk

Vars

active_static_imagesПлоский список образов скрытых турфов - целиком уезжает в client.images
active_static_images_transparentТо же для прозрачного набора; null, пока набор не построен
obscuredTurfsТурфы чанка, которые не видит ни одна камера: турф -> образ статики. Образ привязан к самому турфу, но показывается только через client.images тому, кто смотрит через камерную сеть. Раньше вместо образов в vis_contents каждого скрытого турфа лежала пара движимых объектов, и SendMaps обходил их для КАЖДОГО клиента на карте, а не только для ИИ.
obscured_turfs_transparentТе же турфы со вторым набором образов - прозрачным для мыши. Нужен наблюдателям с USE_STATIC_TRANSPARENT (детектор ИИ в мультитуле): статику там видит живой человек, которому нельзя блокировать клики по миру. Строится лениво, до первого такого наблюдателя тут null.

static_images_forНабор образов статики для наблюдателя с таким режимом. Прозрачный набор строится по требованию: он нужен только детектору ИИ.
still_seen_by_same_clientСмотрит ли в чанк другой глаз того же клиента с тем же режимом статики.
take_static_from_watchersЗабрать образы у всех наблюдателей: списки образов сейчас изменятся.
