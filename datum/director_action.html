Space Station 13 - Modules - Types — Var Details - Proc Details

director_action
/datum/director_action

Базовый контракт всего, что может запустить директор. /datum/round_event_control и /datum/dynamic_ruleset переподвешиваются под него.

Vars

admin_onlyТолько для ручного запуска админом (заменяет хак weight = 0)
antag_heavyДля пула ANTAG: тяжёлая инжекция (nuke assault и т.п.)
costСколько бюджета списывается при запуске
director_kindDIRECTOR_KIND_EVENT или DIRECTOR_KIND_RULESET
director_linked_detailПояснение связанной доступности для каталога профилей.
director_linked_round_typesТипы раундов, где действие не выбирается самостоятельно, но запускается связанным сценарием другого действия. Используется каталогом профилей, а не can_fire().
director_preflight_detailПоследняя неинтерактивная проверка фактической готовности. Панель читает эти поля, поэтому preflight не должен открывать опросы, выдавать роли или менять состояние раунда.
disruptionНавязчивость запуска (DIRECTOR_DISRUPTION_*): насколько действие мешает играть. Мягкие профили режут вес по этой метке (profile.disruption_weight_mults). null = дефолт от severity, см. get_disruption().
earliest_startСамое раннее время раунда (децисекунды от старта)
enabledВыключенное действие никогда не выбирается естественно
familyСемейство однотипных действий (произвольный строковый тег). Члены семейства делят затухание повторов (repeat_falloff считает по запускам всего семейства) и паузу profile.family_spacing: десять вариантов "перелива труб" не обходят анти-повторы поодиночке.
fillerФиллер: пустышки вроде "Nothing" и мигания ламп. Не выбирается гарантированным битом - после долгой тишины директор обязан выдать реальный контент, а не ещё одну тишину.
intensityВклад в активную нагрузку, пока действие живо
intensity_lingerСколько вклад держится после завершения one-shot действия (децисекунды)
max_occurrencesМаксимум естественных запусков (0 = без лимита для базы; событtopia переопределяет)
min_playersМинимальный эффективный экипаж
min_staffingАссоциация DIRECTOR_DEPT_* -> минимум активных; null = без требований
occurrencesСколько раз действие уже запускалось
repeat_penaltyПерсональное затухание повторов вместо профильного (см. director_profile.repeat_penalty); null = профиль
required_round_typeТипы раундов, в которых действие доступно (null = любые)
severityDIRECTOR_SEVERITY_*
weightВес во взвешенном выборе
weight_can_changeВес может стать положительным по живому условию уже во время раунда. Нужен панели: нулевой текущий вес такого действия означает "ждёт условия", а не "выключено".

Procs

action_nameИмя для конфига/логов/панели. Обязано быть уникальным среди действий.
can_fireВсе проверки пригодности. Наследники зовут ..() и добавляют свои.
director_preflightВторая ступень готовности непосредственно перед выбором. null = действие не реализует отдельный preflight и полагается на execute_action(); TRUE/FALSE = явный результат.
execute_actionЗапуск действия. Возвращает TRUE при успехе.
get_disruptionНавязчивость действия: явная метка или дефолт от ступени. Флавор фоновый, minor заметный-но-терпимый, всё тяжелее (и антаг-пулы) - мешающее.
get_weightВес с учётом сигналов. Наследники могут модифицировать.
