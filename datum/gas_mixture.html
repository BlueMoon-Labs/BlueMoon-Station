proc
get_fuel_amount

Топливо смеси при температуре temp. threshold работает ровно как у get_oxidation_power() выше: усечённая сумма для гейтов, полная - без него.

proc
get_oxidation_power
(temp, threshold)

Суммарная окислительная способность смеси при температуре temp.

threshold - необязательный порог для вызывающих, которым нужен только ответ "хватает ли": сумма из неотрицательных слагаемых, поэтому как только она его перевалила, добирать остаток газ-листа незачем и цикл выходит. Возвращённое значение тогда усечено (оно >= threshold, но не полное) - сравнивать с ним можно, использовать как число нельзя. Без аргумента поведение прежнее. Мотив: гейт горящей плитки зовёт этот прок каждый проход на каждом очаге, а в пожаре кислорода заведомо больше порога и он находится на первом-втором газе из шести-девяти.

proc
has_ignitable_fuel
(temp)

TRUE when at least one gas in the mixture has reached its own ignition temperature. Deliberately ignores moles and burn rates: this is a gate in front of the fire reactions, so it must never answer FALSE where get_fuel_amount() would have returned something positive.

proc
remove_specific
(gas_id, amount, /datum/gas_mixture/into)

Removes a specific amount of one gas. Returns a gas_mixture with that gas, or null if amount <= 0. If into is supplied, that mixture is cleared and filled (no allocation); otherwise a new mixture is created.

proc
scrub_into

proc
share_with_template
(/datum/gas_mixture/template, coeff)

One-sided share() against an immutable template mixture (planetary atmosphere): src moves toward the template exactly as share(fresh_template_copy, coeff, coeff) would move it, but nothing is written to the template and no copy is allocated. The template must be archived with gases matching its archive (parse_gas_string does this).
