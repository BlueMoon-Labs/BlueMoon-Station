Space Station 13 - Modules - Types — Var Details - Proc Details

ping_diagnostics
/datum/ping_diagnostics

Разбор пинга одного клиента: кольцо замеров за окно, база, метрики браузера, вердикт.

Клиент сюда не ссылается, только его ckey: тесты собирают датум без клиента. Время - дс по REALTIMEOFDAY, задержки - мс.

Vars

awaiting_batchСамая старая пачка без ответа.
awaiting_sharedТекущее ожидание пришлось на молчание у всех: подвисанием игрока не считается.
base_timeМонотонная очередь минимумов rtt - stall, значения по возрастанию.
byond_build_codebyond_version * 10000 + byond_build.
capacityЁмкость кольца: PING_DIAG_BASE_SAMPLES, у наблюдаемого окном - PING_DIAG_MAX_SAMPLES.
chat_secondПоток чата посекундно за PING_DIAG_FLOOD_WINDOW_DS: номер секунды и сколько сообщений в ней ушло.
chat_sinceС какого момента SSchat шлёт этому клиенту сообщения, null - ещё не слал.
probes_expectedУшедшие ускоренные замеры без ответа: ответ без пробы не принимается.
raw_dumped_untilДо какого времени сырые замеры уже ушли в ping-samples.
sample_excessrtt - stall - база.
sample_floodЗамер пришёл, пока на клиента сыпался чат: в детекторы сети не идёт, его опоздание - очередь, а не подвисание.
sample_sharednull, пока общая доля неизвестна: пачка не закрыта или в ней мало ответивших.
watchersСколько открытых окон смотрят на этот датум: им нужен ускоренный замер.
yours_sinceС какого момента главный вердикт на стороне игрока, 0 - не на его.

Procs

apply_batch_sharedСлот мог уйти под новый замер, пока пачка была открыта: тогда номер пачки не совпадёт.
chat_rateСообщений в секунду за последние PING_DIAG_FLOOD_WINDOW_DS, null - SSchat этому клиенту ещё ничего не слал.
graph_pointsТочки графика за окно. В корзине прореживания берётся замер с наибольшим RTT, чтобы спайки не терялись.
grow_ringОкно диагностики хочет ускоренный замер: кольцо растёт, замеры остаются по порядку. Возвращает список старый слот -> новый для открытых пачек или null, если расти некуда.
hint_dueРешение без побочных эффектов: отметку "уже подсказали" ставит вызывающий. Без общей доли сервер не отличить от сети игрока: при малом онлайне молчим.
note_chatSSchat отправил клиенту пачку из count сообщений.
note_personal_silenceОстальные ответили, а этот молчит дальше: ожидание снова его.
note_replyОпоздание, которое покрывает простой сервера (stall, мс), подвисанием игрока не считается.
note_shared_silenceПачка закрылась при молчании почти у всех: текущее ожидание - беда сервера или канала.
ordered_slotsВсе занятые слоты от старого к новому.
raw_sinceСырые замеры новее after для пересчёта порогов офлайн: "dt/rtt/stall[p][f]", p - ускоренный замер, f - пришёл под потоком чата.
record_probeОтвет на ускоренный замер: принимается, только если проба ушла и ещё не отвечена.
record_sampleЗамер DS-пути. Пачка 0 - ускоренный замер: общую долю берёт из последней закрытой пачки. Числа приходят командной строкой от клиента: нечисло отбрасывается (null), остальное зажимается.
