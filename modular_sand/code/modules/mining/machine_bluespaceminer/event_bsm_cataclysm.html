/proc/bsm_get_all_minersАдминский ивент (weight = 0, admin_only): запускается только вручную через "Admin.Events -> Trigger Event" и наводит tunguska-класс блюспейс-метеорит на цель. Админ может выбрать конкретный турф (любой на станции), турф под собой — либо оставить "Случайный майнер" как цель по умолчанию. Также можно задать сторону света, с которой метеор будет лететь.
/proc/bsm_pick_living_target_onЕсли на таргетном турфе есть живой моб, возвращает его (метеор будет гнаться за ним), иначе возвращает сам турф как статичную цель.
/datum/event_admin_setup/bsm_cataclysm_targetПозволяет админу прицелиться: случайный майнер, текущий турф или любой турф станции (через выбор зоны и точного турфа).
