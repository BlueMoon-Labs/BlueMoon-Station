# Звуки тренировочного полигона

Все файлы каталога распространяются под [Creative Commons Attribution-ShareAlike 3.0 Unported](https://creativecommons.org/licenses/by-sa/3.0/), как и записи-источники. Записи сведены в моно, выровнены по громкости, концы смягчены.

- `enter.ogg` - вход на полигон. `sound/machines/holopadon.ogg` из [TauCetiClassic](https://github.com/TauCetiStation/TauCetiClassic) (Lizurt, PR #3277), CC BY-SA 3.0; срезан низ, сжат пик в начале.
- `sector_load.ogg` - загрузка сектора. `sound/machines/destructive_scanner/TubeUp.ogg` из [/tg/station](https://github.com/tgstation/tgstation) (Qustinnus, PR #54093), CC BY-SA 3.0; срезан низ, сжатие.
- `sector_unload.ogg` - растворение сектора. Та же запись `TubeUp.ogg`, проиграна задом наперёд и замедлена до 0.85.
- `recover.ogg` - восстановление после смерти. `sound/effects/pai/pai_boot.ogg` из [Aurora.3](https://github.com/Aurorastation/Aurora.3) (Wowzewow (Wezzy), PR #14579), CC BY-SA 3.0.
- `step.ogg` - шаг упражнения выполнен. `sound/machines/complete.ogg` из [TauCetiClassic](https://github.com/TauCetiStation/TauCetiClassic) (Basia, PR #13859), CC BY-SA 3.0; обрезан хвост.
- `success.ogg` - упражнение выполнено. `sound/machines/calibration_complete.ogg` из [TauCetiClassic](https://github.com/TauCetiStation/TauCetiClassic) (Basia, PR #13859), CC BY-SA 3.0; обрезаны тишина в начале и хвост.
- `fail.ogg` - упражнение провалено. `sound/effects/psi/power_fail.ogg` из [Aurora.3](https://github.com/Aurorastation/Aurora.3) (Matt Atlas, PR #7717, перенос из Baystation12), CC BY-SA 3.0.
