/proc/click_is_drag_leftoverКлик посреди перетаскивания не считается, кроме ЛКМ при зажатом ПКМ: когда ПКМ карты приходит кликом, клиент шлёт его с drag=right, а это второе действие и Ctrl+ПКМ+ЛКМ (положить вещь под курсор, повернуть)
/proc/mouse_event_is_right_buttonНажатие и отпускание ПКМ. Автоклик и предметы на зажатие (лучевая винтовка) - только для ЛКМ: ПКМ теперь доходит до сервера и вне боя, нажатие ПКМ, чтобы открыть меню, не должно целиться и стрелять
/datum/context_menuМеню действий у курсора.
/proc/context_menu_can_takeВещь можно взять: рядом, не прикручена, не своя, и есть свободная рука - активная или вторая
/proc/context_menu_takeБерёт вещь как ЛКМ по ней; активная рука занята - сперва переключается на свободную
/proc/context_menu_nameИмя объекта для строки меню: без \proper и \improper (capitalize иначе ломает первую букву) и с заглавной
/proc/cmp_context_menu_nameМобы первыми, дальше по алфавиту
