/proc/context_menu_html_controlЭлемент скина браузерного меню по настройке «Слой»
/proc/context_menu_html_windowЧто показывать и прятать: у меню поверх окон - его окно целиком, иначе сам элемент
/proc/context_menu_icon_base64Значок объекта для браузерного меню: основной стейт целиком в base64, по стейту один раз. Прозрачные поля обрезает страница: попиксельный обход в DM стоил десятки мс на значок за один тик. Люди собраны из оверлеев, их основной стейт - пустое тело, им значка нет.
/proc/context_menu_icon_cachedЗначок уже готов (или известно, что его нет): отдать его ничего не стоит
/proc/context_menu_icon_keyКлюч кэша значков; null - значка у объекта не бывает
/proc/context_menu_icon_dirУ однонаправленного стейта другой стороны нет, а вещь в руках и в меню всегда лицом
/proc/context_menu_icon_has_stateЕсть ли стейт в файле иконки; список стейтов файла собирается один раз
