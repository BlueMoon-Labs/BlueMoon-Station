/proc/heretic_pocket_warning_fxИзнанка истончается: оба разрыва мигают до конца, снаружи и внутри слышно предупреждение пути.

/proc/heretic_pocket_collapse_fxИзнанка схлопывается: у входа слышен провал внутрь себя.
/proc/heretic_pocket_exit_fxВыход из изнанки: воздух расходится щелью, фигура проступает из неё, ремесло пути рядом отзывается.
