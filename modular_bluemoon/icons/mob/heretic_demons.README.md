# Демоны Мансуса

`heretic_demons.dmi` использует исходные рисунки из `icons/mob/eldritch_mobs.dmi`: `raw_prophet`, `stalker`, `ash_walker`, `armsy_start`, `armsy_mid`, `armsy_end`. Файл пришёл из tgstation вместе с переносом еретиков; в истории BlueMoon этот перенос отмечен коммитом `eb8574d6d61` автора kiwedespars. Исходный файл не изменён.

Рисунки и производная анимация распространяются по [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/), согласно лицензии звуковых и графических ресурсов проекта. Сохранены исходные силуэты, направления и палитры; у Пепельного духа добавлены тёплые оттенки жара и прозрачные частицы пепла.

Каждое состояние содержит 16 кадров с непрерывным циклом, `movement = 0`. Пророк сохраняет одно направление, остальные — четыре.

| Состояния | Движение | Период |
| --- | --- | --- |
| `raw_prophet` | Подёргивание сшитых конечностей, движение зрачка, короткое моргание. | 2.4 с |
| `stalker` | Дыхание головы, следящий глаз, моргание и покачивание свисающей плоти. Нижние пять рядов, включая ступни, неподвижны. | 3.2 с |
| `ash_walker` | Слабое движение черепа, переменный жар глазниц и поднимающиеся частицы пепла. Нижние двенадцать рядов с опорными ногами неподвижны. | 1.6 с |
| `armsy_start`, `armsy_mid`, `armsy_end` | Волна сокращений внутри плоти; фазы головы, середины и хвоста различаются. Два крайних ряда и столбца каждого кадра совпадают с исходником, чтобы сегменты сохраняли стыки. | 2 с |

Ржавый ходок сохраняет исходный файл и существующие направленные анимации движения.
