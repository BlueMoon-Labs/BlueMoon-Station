# Путь Эха

Ресурсы распространяются по [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/). Для адаптированных спрайтов ниже указаны исходники и авторство.

| Ресурс | Основа и изменения |
| --- | --- |
| Клинок и обе руки | `dark_blade`, EnterTheJake; [источники и авторство](heretic.README.md), [проекции в руках](heretic_visuals.README.md). Верх лезвия заменён двумя разнесёнными загнутыми зубцами. Сохранены полотно рук 48×36 и положение исходной рукояти. |
| Мантия и капюшон | `blade_armor`, OrcaCora и GregorDM; [исходники](heretic_visuals.README.md). Сохранены складки и посадка; добавлены трубы разной высоты, прорезная маска хора, тёмная ряса и две ленты партитуры. Ленты и нижние складки колышутся с запаздыванием, внутри труб последовательно проходит тёплый свет. У мантии по 96 кадров для четырёх направлений с поднятым и опущенным капюшоном; напольные состояния имеют более спокойное движение. Цикл — 4,8 секунды. |
| Поминальная лира | Самостоятельный рисунок: асимметричная костяная рама, латунная перекладина, три струны, деревянная дека и подвесной язычок. Струны колеблются последовательно, язычок качается с запаздыванием. Напольный вид и четыре проекции каждой руки имеют по 48 кадров; цикл — 2,4 секунды. |
| Резонатор | `mania_motor_inactive` из `icons/obj/clockwork_objects.dmi`. Сохранены объёмная подставка и изогнутая рама, добавлены три звучащие трубы и движущиеся блики. |
| Книга | Переплёт Замка и проекции Клинка из [книг проекта](heretic_relics.README.md); анимации открытия и чтения EnterTheJake из [tgstation](heretic.README.md). Живой глаз на обложке и развороте следит за читателем и моргает; струны и нотные страницы движутся в разных фазах. Глаз на развороте расположен ниже парящей печати. Открытие и закрытие занимают по 0,8 секунды. |
| Хватка | `moon_grasp`; [происхождение и авторство](heretic_grasp.README.md). Латунные всполохи, расходящаяся волна и полное затухание. |
| Значки способностей | Пять самостоятельных рисунков 32×32: удар камертона, смещённые звуковые печати, трёхтрубный орган, дирижёрская палочка и поющая маска. У каждого 48 кадров с неподвижной основой и собственным движением звука; цикл занимает 2,4 секунды. |
| Печать | Обод `sigil_lock` из [эффектов проекта](heretic_visuals.README.md). Собственный центральный знак меняет форму: дуги расходятся с запаздыванием, внутренний просвет сжимается, по контуру проходит свет. Цикл — 48 кадров за 2,4 секунды. |
| Метка, нимб и звуковые волны | Собственные рисунки с расходящимися и затухающими фронтами. Наземный Остаточный звон использует отдельный непрерывный цикл `echo_ringing`; одноразовый `echo_wave` применяется только для вспышек. |

Все эффекты имеют полотно 32×32 с шагом 0,05 секунды. `echo_grasp`, `echo_burst` и `echo_wave` проигрываются один раз за 0,8 секунды. У метки и предупреждения цикл 1,2 секунды; у нимба и Остаточного звона — 2,4 секунды. У предупреждения центр клетки и угловые отметки видны во всех кадрах.
